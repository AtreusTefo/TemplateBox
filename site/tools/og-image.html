Open Graph Card Generator

Renders the 1200 x 630 social preview card used by og:image and twitter:image. The site points those tags at assets/logo.png by default, which is a square logo at 489KB: social platforms crop or letterbox it to their 1.91:1 frame, and it is heavier than it needs to be for an asset every crawler fetches.

Documents are drawn with the native Canvas API, the same approach as the poster and mockup editors, so this tool needs no image assets, no dependency and no server.

What to do with the file
  1. Save the downloaded file into the project's assets/ folder, keeping the filename the tool suggests.
  2. On the matching page, change the og:image and twitter:image values from assets/logo.png to the new file.
  3. Deploy, then re-scrape the URL in the Facebook Sharing Debugger, the X Card Validator and the LinkedIn Post Inspector so the platforms drop their cached version.
Why one card per page is worth the extra few minutes

A single generic card works, but a shared link to the rent receipt page that actually shows a rent receipt tells the reader what they are getting before they tap. The presets above cover every landing page, and each one sets its own filename, so producing the full set is a matter of stepping through the dropdown and clicking Download each time.
