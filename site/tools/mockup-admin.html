Mockup Template Factory

Internal tool. Everything runs locally in this tab -- nothing is uploaded. Load a base photograph, mark the print area, derive the fabric maps, tune the displacement against a test design, then download the assets and paste the registry entry.

1. Base image and print area

Load a base image, then click the print area's corners in order: top-left, top-right, bottom-right, bottom-left. For a "window" base the corners are the edges of the transparent opening.

No image loaded.

2. Fabric maps

Derived from the photograph's own luminance. Fabric is classified, the silhouette is filled before blurring so the garment edge does not leak a false gradient, then a Sobel gradient becomes the displacement map. Shading and specular split around the fabric's median, so the print darkens in folds and lifts on ridges instead of being uniformly dimmed. A separate tone map (normalised to the garment's peak) drives recolour, because screening the specular over a dye washes dark colours out. Rigid templates (frames, cards, boxes) do not need any of this -- leave it off.

Saturation separates fabric from skin; luma drops dark items like jeans and hair; alpha drops a cut-out background. Check the mask preview before trusting the maps.

3. Preview and strength

A hard grid is the diagnostic case: straight lines have nowhere to hide, so the right strength is the largest one where the grid still reads as printed rather than melted.

Load an image to preview.

4. Thumbnail

4:5 crop centred on the print area, flattened onto white, encoded as JPEG. Keep it under roughly 100KB -- the catalog carries one per template.

5. Registry entry

A taxonomy path, and the same one is written into both trees: assets/mockups/<category>/ for the maps and assets/thumbnails/product-mockups/<category>/ for the thumbnail. Nest as deep as the product needs -- apparel/t-shirts, apparel/hats/baseball-caps, drinkware/mugs, packaging/boxes, print/posters-and-frames. Lowercase and hyphenated; slashes are kept, everything else is slugged. Leave the word "mockup" out of the segments, the tree is already under assets/mockups/.

  1. Create site/assets/mockups/<category>/ and site/assets/thumbnails/product-mockups/<category>/ if this is the first template in that category -- git tracks files, not directories, so a category folder only exists once it holds something.
  2. Save the map downloads into the first and the thumbnail into the second.
  3. Save the base photograph itself as <id>-base.png beside the maps.
  4. Paste the entry into js/mockup-templates.js.
  5. Add a catalog card in index.html with data-target="mockup" data-doc="<id>".
  6. Run node tests/verify-layout.js.
